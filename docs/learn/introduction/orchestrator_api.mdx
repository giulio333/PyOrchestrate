# Orchestrator API

The external Orchestrator API is a ZeroMQ command interface over TCP. The orchestrator binds a ROUTER socket and external clients connect with DEALER sockets.

## Interfaces

- **CLI:** interactive runtime inspection and control through commands such as `ps`, `status`, `start`, `stop`, `history`, and `shutdown`.
- **Web interface:** a read-only HTTP layer that queries the same command interface and renders HTML or JSON.

## Configuration

```python
from PyOrchestrate.core.orchestrator import Orchestrator

config = Orchestrator.Config(
    enable_command_interface=True,
    command_zmq_address="tcp://127.0.0.1:5555",
)

orchestrator = Orchestrator(config=config)
```

The CLI connects to `tcp://127.0.0.1:5555` by default:

```bash
pyorchestrate status
```

## Capabilities

Through the CLI you can:

- inspect orchestrator and agent state;
- start or stop registered agents;
- inspect dependencies and command permissions;
- collect runtime statistics;
- query event history;
- request graceful shutdown.

The web interface exposes monitoring operations only.

## Security

The command transport does not provide authentication or encryption. Bind to loopback for local-only use:

```python
command_zmq_address="tcp://127.0.0.1:5555"
```

When remote access is required:

- use a private network and firewall rules;
- restrict operations with `allowed_commands`;
- avoid exposing the ZeroMQ port directly to the public internet;
- protect the web interface with bearer authentication and HTTPS.
