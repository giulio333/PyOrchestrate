# CLI Examples

These examples use the current ZeroMQ command interface and the default local client endpoint, `tcp://127.0.0.1:5555`.

## Start a CLI-Controlled Orchestrator

Use daemon mode when the orchestrator should remain available after its agents finish:

```python
from PyOrchestrate.core.orchestrator import Orchestrator, RunMode

config = Orchestrator.Config(
    enable_command_interface=True,
    command_zmq_address="tcp://127.0.0.1:5555",
    run_mode=RunMode.DAEMON,
)

orchestrator = Orchestrator(config=config)

# Register agents here.

orchestrator.start()
orchestrator.join()
```

In another terminal:

```bash
pyorchestrate status
pyorchestrate ps
pyorchestrate commands
```

## Use a Custom Endpoint

Configure the orchestrator:

```python
config = Orchestrator.Config(
    command_zmq_address="tcp://127.0.0.1:5560",
)
```

Pass the same endpoint to every client:

```bash
pyorchestrate ps --socket tcp://127.0.0.1:5560
pyorchestrate-web --socket tcp://127.0.0.1:5560
```

## Inspect Agents

```bash
# List every registered agent
pyorchestrate ps

# Inspect the orchestrator
pyorchestrate status

# Inspect a single agent
pyorchestrate status Worker

# Show the dependency graph
pyorchestrate dependencies
```

## Control Agents

The relevant commands must be allowed by the orchestrator configuration:

```bash
pyorchestrate start Worker
pyorchestrate stop Worker
```

For an operationally read-only deployment:

```python
config = Orchestrator.Config(
    command_zmq_address="tcp://127.0.0.1:5555",
    allowed_commands="monitoring",
)
```

Inspect the effective policy:

```bash
pyorchestrate commands
```

## Query Event History

```bash
# Last 20 events
pyorchestrate history --last 20

# Events for one agent
pyorchestrate history --agent Worker

# Events with one event name (stored enum value, lowercase)
pyorchestrate history --type agent_registered

# Events after a known sequence number
pyorchestrate history --after-seq 100

# Aggregated statistics
pyorchestrate history-stats

# Aggregated statistics for one agent
pyorchestrate history-stats --agent Worker
```

The history holds registration events, the agent messages routed as start, ready, heartbeat, error and termination, and everything emitted through `orchestrator.event_bus.emit(...)`. It is a ring buffer sized by `history_max_events`, so the oldest events are dropped once it is full.

## Monitor Resource Usage

Refresh every five seconds:

```bash
pyorchestrate stats --interval 5
```

Press `Ctrl+C` to stop the monitor.

## JSON Automation

Successful JSON output contains command data at the root:

```bash
STATUS=$(pyorchestrate status --format json)

echo "$STATUS" | jq '.running_agents'
echo "$STATUS" | jq '.total_agents'
```

List stopped agents:

```bash
pyorchestrate ps --format json |
  jq -r '.agents[] | select(.alive == false) | .agent_name'
```

Restart registered agents that are not alive:

```bash
for agent in $(pyorchestrate ps --format json |
  jq -r '.agents[] | select(.alive == false) | .agent_name'); do
  pyorchestrate start "$agent"
done
```

## Health Check

```bash
#!/usr/bin/env bash

set -u

ZMQ_ADDRESS="tcp://127.0.0.1:5555"

STATUS=$(pyorchestrate status \
  --socket "$ZMQ_ADDRESS" \
  --format json)

RUNNING=$(echo "$STATUS" | jq -r '.running_agents')
TOTAL=$(echo "$STATUS" | jq -r '.total_agents')

echo "Orchestrator reachable: $RUNNING/$TOTAL agents running"
```

The current CLI prints connection failures as text. If a script needs strict failure detection, validate that the result parses as JSON before consuming it.

## Read-Only Web Monitoring

```bash
pyorchestrate-web \
  --host 127.0.0.1 \
  --port 8000 \
  --socket tcp://127.0.0.1:5555
```

Open:

```text
http://127.0.0.1:8000
```

Request machine-readable data:

```bash
curl \
  -H "Accept: application/json" \
  http://127.0.0.1:8000/api/orchestrator/status
```

## Authenticated Web Monitoring

```bash
AUTH_TOKEN=$(openssl rand -hex 32)

pyorchestrate-web \
  --host 127.0.0.1 \
  --port 8000 \
  --socket tcp://127.0.0.1:5555 \
  --enable-auth \
  --auth-token "$AUTH_TOKEN"
```

```bash
curl \
  -H "Authorization: Bearer $AUTH_TOKEN" \
  -H "Accept: application/json" \
  http://127.0.0.1:8000/api/agents
```

## Graceful Shutdown

For a daemon-mode orchestrator:

```bash
pyorchestrate shutdown
```

If command restrictions are active, `shutdown` must be included in `allowed_commands`.
